MODELOS DE SKETCHFAB PARA EL CUARTO 2 (DIRECCIÓN)
==================================================

El constructor del Cuarto 2 ya los busca. Si el archivo no está, usa el modelo de
Poly Haven de siempre, así que el cuarto funciona igual esté o no esté cada uno.
Son todos CC BY (la misma licencia que los del Cuarto 3) y livianos para el Quest.

CÓMO BAJAR CADA UNO
-------------------
1. Abrir el enlace (hay que estar logueado en Sketchfab).
2. Botón "Download 3D Model".
3. Elegir el formato "glTF" (el que dice .glb / Autoconverted format).
4. Se baja un .zip: adentro está el .glb.
5. Copiar ese .glb a esta carpeta (Assets/Sketchfab) con EXACTAMENTE el nombre
   que dice la lista de abajo (respetando mayúsculas y guiones bajos).
6. Volver a Unity y correr: Escape Room > Construir Cuarto 2.
